# Mark registry

The population size distribution f(Q | θ) as one registry shared by the population fit, the missing-mass simulator and the total-emission estimator: a power law, a lognormal, a lognormal body spliced continuously to a Pareto tail, and a mixture of lognormals. Each family has `log_prob`, `sample`, the partial first moment `truncated_mean` that the totals need, and `numpyro_prior` for its default priors. **Tier V.**
