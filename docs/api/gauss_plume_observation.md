# Column observation

The column + averaging-kernel observation every transport tier shares: `ColumnObservation` turns a concentration field on the analysis grid (Tiers II and III) or per-receptor profiles (the Tier I plume, through `coupled.column_response`) into the column-mass enhancement a satellite sees. **Tier I**, reused by Tiers II–IV.
