# Total emission

The basin total emitted mass from a TMTPP posterior, as posterior samples split into detected and inferred-missing mass, with the mass-rate over the observed windows. `M_total = Λ E_f[Q] D` needs a mean event duration `D` in the reciprocal of the flux's time unit, so the mass is in kg. The rate is `M_total / T_eff`, with `T_eff` the length of the union of the observed windows, the same windows `Λ` integrates over. **Tier V.**
